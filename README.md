# Guevara Câmbio — base operacional
Inclui cadastro/login, perfis, cotações, ordens, comprovativo de transferência, estados, área admin, taxas, PostgreSQL, API Express e código de levantamento de uso único.

IMPORTANTE: isto é uma base técnica. Não torna automaticamente a empresa autorizada a operar câmbio nem conecta a um banco. Antes de dinheiro real: configurar banco/provedor, KYC/AML, segurança, HTTPS, políticas e autorizações aplicáveis.

GitHub Pages hospeda apenas o frontend estático; a API precisa de hospedagem própria.

Instalação: Node 20+, PostgreSQL; copie .env.example para .env; npm install; npm run db:init; npm start.
